The finding is resolved by kino://5720302421d8748ea19b23da1f119f7c0e7514753b340ae5e425fa7e48588b41. A governed node accepts `{context, repo?, lease}`, validates those values, and composes the worker argv, environment, and terminal view itself. `kudo-node/src/worker.rs` implements it, and the worker tests cover composition and a vouched start.

This deliberately keeps moco's generic ad-hoc start narrow rather than adding caller-selected environment or terminal fields to it. Record the existing design and implementation; no new code or spec version is needed.
