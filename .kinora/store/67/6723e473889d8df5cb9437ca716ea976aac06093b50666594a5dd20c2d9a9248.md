# Decision — same-title contexts already have distinct identities

The finding is resolved in the current implementation. `create_context_with_options` writes a random nonce into every context card, so identical titles and creation seconds do not produce the same identity. The regression test `two_contexts_with_one_title_born_in_one_second_are_two` verifies two ids, two listed contexts, and no shared head history.

Record the existing fix; no code or spec change is needed. Rejected: creator lease/node counters, which would add identity inputs without improving on the nonce.
