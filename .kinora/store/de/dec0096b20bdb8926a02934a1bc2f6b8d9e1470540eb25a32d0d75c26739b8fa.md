# Spec — a context declares the node its woken workers start on

**Contract.** A context may declare a **wake node** (`kudo-shim context
wake-node <ctx> <node>`), written as its own kino; the latest declaration
wins. Without one, a woken worker starts on the node of the context's first
repo (by name), else on the waker's own node.

Wake nodes and the repo nodes they default from use the hub-qualified registry
name, such as `edger::yolo`; the waker routes the typed worker start to that
full name. Existing unqualified declarations remain local aliases during
explicit migration. The launched worker recognizes its declaration by full
name or final `::` segment, as
kino://b53b7abd832f2cd0e58e5084f5733af5d56f762c52cd6fd404913911920a6de9
specifies for repos.

**Chosen.** Where a context's work runs is the context's to say, as its repos
are; the default follows the repos, so most contexts need nothing. Qualified
names make that choice unambiguous across peer hubs.

**Rejected.** Always the waker's node (a context whose repos live elsewhere
would wake where its work is not). Auto-qualifying old declarations through a
hub (a collision cannot be migrated by guessing).

**Escape hatch.** The worker reaches any other node through governed jobs.
