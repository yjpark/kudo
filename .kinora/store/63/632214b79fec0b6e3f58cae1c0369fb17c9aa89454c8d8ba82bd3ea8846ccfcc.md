# Decision — jig gains rust.extraSrc as a path list

Fix the source-selection problem in jig rather than keeping kudo's `doCheck = false` workaround. Add `rust.extraSrc`, a list of workspace-relative paths merged into crane's Rust source, so tests can read non-Rust fixtures. Kudo will use `rust.extraSrc = [ "docs" "crates/kudo-node/packaging" ]` (or the paths jig's workspace-relative API requires) and restore the package's normal test run after the jig update.

Rejected: a kudo-only source override (duplicates the mechanism), permanently disabling checks, and adding a filter-function API before a use case needs it. Keep the path-list API small; a future fixture-matching need can add a filter without changing this decision.

Open: implementation and verification happen in jig, then kudo removes the workaround. This note records intent only; neither repository has been changed by the design session.
